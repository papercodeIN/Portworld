## 🔍 Explore the Port Pi 3A SBC

Unbox, build, and power up your next DIY project with the **Port Pi 3A Single Board Computer** from Portworld.

**Specs:**  
- SoC: RockChip RK3568  
- RAM: 4GB  
- Storage: 32GB eMMC  
- Connectivity: WiFi + Bluetooth  
- OS Support: Android 11 & Debian Linux
